# Sample photographs (not in use)

Files here are parked, not live. Nothing in this folder is read by the app.

To put one back into use, move it into `src/photos/`:

```bash
mv samples/navratna-chivda.jpg src/photos/
```

It then becomes that product's card picture instead of its 3D render.

**Worth knowing before you do:** every product currently shows its 3D render
on the card and the same model in 360, so the two always match. A photograph
replaces the card picture only — the 360 still shows the model — so that one
product's card and its 360 would no longer be the same image.
